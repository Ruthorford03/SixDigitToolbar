# nhentai快捷 (SixDigitToolbar)

一套為紳士打造的高效同人誌快捷工具。專注於在 Android 行動裝置上實現「**剪貼簿/選字 ➔ nhentai ➔ wnacg 自動化填入 ➔ 本地 AI 漢化**」的極致連動體驗。

---

## ✨ 核心特色

1. **極速代碼跳轉**：
   - 複製 6 位數字後打開 App，一鍵前往。
   - 支援系統選取文字快捷浮動工具列（`PROCESS_TEXT`），長按數字直接「前往nhentai」。
   - 首頁支援**「手動輸入 6 位代碼」**彈窗，未複製亦可秒查。
2. **智慧標題解析與查詢紀錄**：
   - 背景自動透過 nhentai API v2 / HTML 抓取日文作品名稱。
   - 具備防偽過濾機制，自動排除 Cloudflare 防護頁等假標題。
   - 支援自訂基礎網址與鏡像站 Host API。
   - 支援查詢紀錄**即時關鍵字搜尋過濾**與**單筆刪除**，附帶清除防呆保護。
3. **wnacg 自動化貼上助手**：
   - 整合 Android 無障礙服務（AccessibilityService）。
   - 點擊「wnacg」按鈕自動將作品標題複製到剪貼簿、開啟 wnacg App，並**自動點擊搜尋欄填入標題**。
4. **現代化視覺與效能最佳化**：
   - 針對 Android 16 / OriginOS 6 全螢幕邊距、手勢導航與透明系統列最佳化。
   - 完整支援深色模式（Dark Mode），自動跟隨系統或手動切換。
   - 自適應刷新率（144 Hz 動態升降）與按壓微動效。
